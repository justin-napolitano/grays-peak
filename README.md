# Gray's Peak

This repository contains notes and documentation related to hiking Gray's Peak, a relatively easy 14er located about an hour west of Denver. The content includes trip details, gear lists, and trail observations.

## Features

- Detailed hike notes including coordinates, elevation, and trailhead access
- Gear recommendations based on personal experience
- Photographic documentation of the approach and trailhead

## Tech Stack

- Markdown for documentation
- Static content with images

## Getting Started

Clone the repository to review the documentation and images:

```bash
git clone https://github.com/justin-napolitano/grays-peak.git
cd grays-peak
```

Open `index.md` in a Markdown viewer or editor to read the hike notes.

## Project Structure

```
/grays-peak
  /images           # Images related to the hike
  index.md          # Main hike documentation
```
